## 音楽モード（旋法）エクスプローラー

イオニアン〜ロクリアンの7つのモードをWeb Audio APIで試聴し、ピアノロールで音程差を視覚化。各モードの雰囲気と代表的な楽曲例を解説する音楽学習ツール。

### 機能
- 7モード（イオニアン/ドリアン/フリジアン/リディアン/ミクソリディアン/エオリアン/ロクリアン）選択
- ルート音選択（C〜B）でピアノロール即時更新
- スケール再生ボタンで音階を順番に試聴
- ピアノロールでモード内音をカラーハイライト（ルート音=紫）
- 各モードの音程列・雰囲気・代表楽曲を解説

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Web Audio API（音声生成）
